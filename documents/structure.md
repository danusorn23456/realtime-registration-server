# Server structure

```
realtime-registration-server/
├── src/
│   ├── app.ts           # entry point — boots Express, Socket.IO, routes
│   ├── db.ts            # SQLite connection + schema
│   ├── logger.ts        # shared logger
│   ├── route/           # REST routes + data access
│   ├── listeners/       # Socket.IO connection handlers, one per namespace
│   ├── events/          # internal event bus connecting the two namespaces
│   ├── validation/      # server-side validation rules
│   ├── utils/           # small cross-cutting helpers
│   ├── state/           # in-memory, non-persisted runtime state
│   └── types.ts         # shared TypeScript types
├── data/                 # generated at runtime, gitignored
├── dist/                 # generated by `npm run build`, gitignored
├── documents/             # architecture docs (this file + architecture.md)
├── tsconfig.json
└── package.json
```

## `src/app.ts`

Entry point — boots Express, attaches Socket.IO, mounts REST routes, and
wires up the socket namespaces.

## `src/db.ts`

Owns the single SQLite connection and schema.

## `src/logger.ts`

Shared logger used across the app instead of `console.*`.

## `src/route/`

REST endpoints and the data-access layer they (and the socket listeners)
read/write through.

## `src/listeners/`

Socket.IO connection handlers, one file per role/namespace — where incoming
socket events are handled and outgoing ones are broadcast.

## `src/events/`

An internal event bus that lets the two namespaces react to each other's
activity without importing one another directly.

## `src/validation/`

Server-side validation rules, used to reject invalid submissions.

## `src/state/`

Plain in-memory data scoped to the running process — not persisted, reset on
restart. For transient, live-connection-derived data that doesn't belong in
the database.

## `src/utils/`

Small, generic helpers with no domain knowledge.

## `src/types.ts`

Shared TypeScript types used across the server.

## `data/` (not committed)

Runtime database files, generated on demand.

## `dist/` (not committed)

Compiled JS output — what the production start script runs.
